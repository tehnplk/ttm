# คู่มือการใช้งานสำหรับผู้ใช้ (ละเอียด + จุดใส่รูป พร้อมแปลง Word)

> ใช้ไฟล์นี้เป็นต้นฉบับ เปิดใน Word / Google Docs แล้วแทรกรูปตามจุดที่ระบุ จากนั้นบันทึกเป็น `.docx`

## สารบัญ
1. ภาพรวมและการเข้าสู่ระบบจอง  
2. ขั้นตอนจองคิว (ละเอียด พร้อมจุดใส่รูปแต่ละขั้น)  
3. ตรวจสอบสถานะ / ค้นหาตั๋วที่จองแล้ว  
4. คำถามพบบ่อย (FAQ) ใน LINE  
5. การแจ้งเตือนผ่าน LINE (ตัวอย่าง Flex)  
6. ช่องทางติดต่อ

---

## 1) ภาพรวมและการเข้าสู่ระบบจอง
- เว็บไซต์จองคิว: `https://<โดเมนของคุณ>/booking`
- ไม่ต้องล็อกอินสำหรับการจอง
- รองรับการใช้งานบนมือถือ / แท็บเล็ต / คอมพิวเตอร์

**จุดใส่รูป:** ภาพหน้า Landing/จองคิว (แนะนำแนวนอน 16:9)

---

## 2) ขั้นตอนจองคิว (ละเอียด)

### 2.1 เลือกสาขา
1) เข้าเว็บ `/booking`  
2) เลือกสาขาที่ต้องการ (ระบบเรียงสาขาใกล้ตัวเมื่อเปิด Location)  
3) กดเลือกสาขาเพื่อไปขั้นถัดไป  

**จุดใส่รูป:** หน้าเลือกสาขา (การ์ดสาขา)

### 2.2 เลือกบริการ
1) เลือกบริการ/แพ็กเกจที่ต้องการ  
2) กด “ถัดไป”  

**จุดใส่รูป:** หน้าเลือกบริการ

### 2.3 เลือกวันที่และเวลา
1) เลือกวันที่ในปฏิทิน  
2) เลือกช่วงเวลาที่ว่าง (ปุ่มเวลา)  

**จุดใส่รูป:** หน้าเลือกวัน/เวลา (ปุ่มเวลา)

### 2.4 เลือกพนักงาน
1) ระบบแสดงรายชื่อพนักงาน  
2) หากพนักงานมีคิวช่วงเวลานั้น ปุ่มจะเป็นสีจางและขึ้นข้อความ **“มีจองแล้ว”** (กดไม่ได้)  
3) เลือกพนักงานที่ว่าง แล้วกดถัดไป  

**จุดใส่รูป:** หน้าเลือกพนักงาน (เห็นปุ่มถูก disable และข้อความ “มีจองแล้ว”)

### 2.5 กรอกข้อมูลและยืนยัน
1) กรอกชื่อผู้จอง เบอร์โทร ข้อมูลเพิ่มเติม (ถ้ามี)  
2) ตรวจสอบสรุปการจอง → กด “ยืนยัน”  
3) ระบบแสดงหน้าสำเร็จ พร้อมรหัสการจอง/QR (ถ้าตั้งค่า)  

**จุดใส่รูป:**  
- หน้าใส่ข้อมูลผู้จอง  
- หน้าสำเร็จ (มีรหัส/QR ถ้ามี)

**หมายเหตุ:** หากเวลาที่เลือกถูกจองแล้ว ปุ่มเลือกพนักงานจะปิดและแสดง “มีจองแล้ว”

---

## 3) ตรวจสอบสถานะ / ค้นหาตั๋วที่จองแล้ว
1) จากหน้าแรก กดปุ่ม **“ตรวจสอบสถานะ / ค้นหาตั๋ว”**  
2) กรอกข้อมูลที่ระบบกำหนด (เช่น เบอร์โทร หรือรหัสจอง)  
3) ดูรายละเอียดการจองได้ทันที  

**จุดใส่รูป:** หน้า “ตรวจสอบสถานะ / ค้นหาตั๋ว”

---

## 4) คำถามพบบ่อย (FAQ) ใน LINE
1) พิมพ์ “คำถามพบบ่อย” ใน LINE หรือกดปุ่ม “3. คำถามพบบ่อย”  
2) ระบบจะแสดง FAQ แบบ Flex Message เป็นการ์ดเลื่อน (Carousel)  

**จุดใส่รูป:** ตัวอย่าง FAQ Flex ใน LINE (การ์ดเลื่อน)

---

## 5) การแจ้งเตือนผ่าน LINE (ตัวอย่าง Flex)
- ก่อนถึงเวลานัด ระบบจะส่งข้อความแจ้งเตือนทาง LINE อัตโนมัติ  
- ข้อความเป็น Flex มีข้อมูลนัด: เลขที่จอง, ชื่อ, วันที่, เวลา, สาขา/บริการ/พนักงาน (ถ้ามี)  
- มีข้อความเตือน **“กรุณามาถึงก่อนเวลา 15 นาที”** ด้านล่าง  

**จุดใส่รูป:** ตัวอย่าง Flex แจ้งเตือนใน LINE

---

## 6) ช่องทางติดต่อ
- หากพบปัญหาในการจอง / ตรวจสอบตั๋ว / รับแจ้งเตือน  
  - ช่องทาง: (ระบุ เช่น โทร / LINE OA / อีเมล)  
  - เวลาให้บริการ: (ระบุ)

---

## วิธีแปลงไฟล์นี้เป็น Word และใส่รูป
1) เปิด `docs/user-guide-user.md` ใน Word หรือ Google Docs  
2) แทรกรูปตาม “จุดใส่รูป” ที่ระบุในแต่ละหัวข้อ  
3) ปรับข้อความโดเมน/ช่องทางติดต่อให้ตรงของจริง  
4) บันทึกเป็น `.docx` ส่งมอบผู้ใช้

> ถ้าต้องการให้เราช่วยใส่รูปจริง โปรดส่งสกรีนช็อต/ไฟล์ภาพมาได้เลย
